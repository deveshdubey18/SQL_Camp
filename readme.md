# SQL Camp
A simple repository for learning and practicing SQL with MySQL.

This repo contains SQL cheat sheets, MySQL concepts, and practice questions for learning, revision, and interview preparation.

# 📚 What's Inside
## CheatSheets
Quick reference notes for:
- DDL Commands
- DML Commands
- DQL Commands
- DCL Commands
- MySQL Programming Concepts
- Triggers


## Practice
A collection of SQL practice sets covering different SQL concepts and query-solving problems.
