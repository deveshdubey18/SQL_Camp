# SQL Camp 🏕️

A beginner-friendly repository for learning and practicing **SQL with MySQL**. It brings together concise cheat sheets, core MySQL concepts, and practice sets to support learning, revision, and SQL interview preparation.

## 📚 What's Inside

### Cheat Sheets

Quick-reference notes for common SQL and MySQL topics:

| Topic | Description |
|---|---|
| [DDL Commands](CheatSheets/DDL_commands.md) | Create and manage databases and tables |
| [DML Commands](CheatSheets/DML_commands.md) | Insert, update, and delete data |
| [DQL Commands](CheatSheets/DQL_commands.md) | Query, filter, sort, group, and join data |
| [DCL Commands](CheatSheets/DCL_commands.md) | Manage users and privileges |
| [MySQL Programming Concepts](CheatSheets/MySQL_Programming_concepts.md) | Variables, conditions, loops, procedures, functions, cursors, and error handling |
| [SQL Functions](CheatSheets/SQL_Functions.md) | String, numeric, date/time, aggregate, conditional, and conversion functions |
| [Transactions](CheatSheets/Transactions.md) | Transaction control, savepoints, isolation levels, and ACID properties |
| [Triggers](CheatSheets/Triggers.md) | Trigger events, timing, and row references |

### SQL Practice Sets

The `practice/` folder contains **24 practice files** with SQL questions and query-solving exercises.

Browse the [Practice folder](practice/) and work through the sets to strengthen your understanding of SQL concepts.

## 🧠 Topics Covered

- Database and table creation and modification
- Data insertion, updating, and deletion
- Data retrieval, filtering, sorting, and limiting
- Aggregate functions and grouping with `GROUP BY` and `HAVING`
- Joins and subqueries
- Set operators such as `UNION` and `UNION ALL`
- MySQL functions and expressions
- User management and access privileges
- Stored procedures, stored functions, cursors, and control flow
- Transactions, savepoints, ACID properties, and isolation levels
- Triggers

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/deveshdubey18/SQL_Camp.git
   ```

2. **Open the project folder**
   ```bash
   cd SQL_Camp
   ```

3. **Choose a topic**  
   Start with the cheat sheets in `CheatSheets/`, then practice using the exercises in `practice/`.

> The repository contains Markdown learning materials. To run SQL examples or write your own queries, use a MySQL environment such as MySQL Server with MySQL Workbench.
