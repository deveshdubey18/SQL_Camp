# ***Triggers Continue***

# 10. DROP TRIGGER
Meaning / Use:
Used to delete an existing trigger.

Syntax:
```
DROP TRIGGER <trigger_name>;
```
Example:
```
DROP TRIGGER before_employee_insert;
```

# 11. SHOW TRIGGERS
Meaning / Use:
Displays all triggers in the currently selected database.

Syntax:
```
SHOW TRIGGERS;
```
Example:
```
SHOW TRIGGERS;
```
